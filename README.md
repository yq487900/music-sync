# MusicSync

> ## ⚠️ 使用警告
>
> **本项目仅限个人本地使用，没有任何登录/鉴权，切勿直接暴露于公网。**
> 面板可以在无密码的情况下被任何能访问到它的人完全控制（包括读取你的网易云 Cookie、
> 下载/删除文件）。请只在你自己信任的局域网内运行；如需外网访问，必须套一层
> 带认证的反向代理（如 Caddy/basic auth 或带登录的反代）。

网易云歌单同步工具：勾选歌单 → 自动拉取曲目 → 按音质优先级下载到本地 → 写歌词 / 封面 / 标签 / NFO → 备份到网易云云盘。

## 架构（单容器）

```
浏览器 ──► musicsync (:13570)  Web 界面 + 同步引擎 + 下载/上传队列
             ├─ ncm-api    (127.0.0.1:3000)  网易云接口服务，处理签名/加密
             └─ lx-runner  (127.0.0.1:3100)  洛雪兼容音源脚本沙箱
```

三个进程跑在**同一个容器**里，由 supervisor 统一托管；后两个只监听容器内回环，不对外暴露。

> 网易云网页接口需要一套签名/加密，直连会出现「扫了码却一直停在等待扫码」「歌单取不到」等问题，
> 因此所有网易云请求统一经 `ncm-api` 转发。详见 `docs/同步改造方案.md`。

## 快速开始

```bash
git clone https://github.com/yq487900/music-sync.git
cd music-sync

cp .env.example .env          # 按需修改 APP_PORT / MUSIC_DOWNLOAD_DIR / MUSIC_LIBRARY_DIR / MUSIC_TRASH_DIR
docker compose up -d
```

访问 `http://<NAS_IP>:13570`

**或者直接用已构建好的镜像**（不用源码、不用构建，架构 amd64）：

```bash
docker compose -f docker-compose.ghcr.yml up -d
```

镜像地址：`ghcr.io/yq487900/music-sync:latest`（打 tag 会自动构建并发布对应版本镜像；版本镜像 tag 不带 v 前缀，如 v0.1.0 → 0.1.0）

> 构建期默认使用国内镜像源（清华 PyPI / npmmirror）。
> 如在海外构建：`docker compose build --build-arg PIP_INDEX=https://pypi.org/simple --build-arg NPM_REGISTRY=https://registry.npmjs.org`

## 首次使用

1. **配置页顶部**扫码登录网易云（失败时页面底部「高级：手动填 Cookie」兜底）
2. **歌单** → 列出账号全部歌单（默认 10 个/页），点歌单看详情
3. **歌单详情** → 勾选要下载的曲目（默认 20 首/页），或整单全选
4. **下载** → 点「下载勾选的」，队列里可暂停 / 继续 / 取消
5. **云盘** → 把下好的歌备份到云盘（可开自动上传）

## 页面功能

| 页面 | 能力 |
|---|---|
| 首页 | **账号卡片（头像/昵称/UID/等级/歌单数/黑胶VIP等级与到期/云盘占用）** · 12 项状态卡片（曲目/云盘/回收站/监控/索引/队列…） · 手动同步/下载 · 实时进度 |
| 歌单 | 账号歌单分页浏览（默认 **10/页**）、封面、勾选同步、点开看详情 |
| 歌单详情 | 曲目列表（默认 **20/页**）· 每首可勾选、单独下载、**单独指定音源** · 全选/取消（本页或整单） · **刷新按钮**（重拉曲目 + 重索引云盘）· **扫描补齐这个歌单**（先预演再排队）· 显示本地是否已下载 / 在不在云盘 / 失败原因 |
| 下载 | **下载队列**（进度、音质、所用音源、暂停/继续/取消）· 曲目列表（默认 **20/页**）· 勾选与批量操作 |
| **整理** | **曲库体检** · **待整理 / 整理后两个独立目录卡片**（各自排序、标签/封面/歌词/**是否在云盘**筛选、搜索、勾选、批量操作、分页）· 一键批量刮削（补标签/封面/歌词）· 逐首编辑 + **按网易云歌曲 ID 手动匹配** · **刮削来源可选 网易云/QQ音乐/酷我/酷狗/咪咕** · 候选带封面专辑 · **不在云盘时点云朵上传图标可直接上传（含外来的本地歌，可顺带加入多个歌单）** · 删除走回收站 |
| 云盘 | 云盘歌曲列表（**走常驻索引，秒回** · 可搜整个云盘 · 筛选：封面/信息、在本地、在歌单）· 每行状态图标（💾本地 / ☁云盘 / 列表在不在歌单）· **点「不在歌单」图标可直接加到歌单** · 配额 · 本地待上传列表 · 单个/批量上传 · **逐首「编辑」按 ID 匹配纠错** · 上传队列 · 删除 |
| **回收站** | 只放整理里移出的歌（**没真删**）· 单首/批量/全部 恢复或彻底清空（真实删除本地文件）· 勾选与搜索 |
| 歌单监控 | 开关 + 两种方式（**从现在开始监控** / **全量扫描补齐后再监控**）· 歌单里加了新歌自动下载，下载完按开关自动上传云盘 · 每轮处理上限可调 |
| 配置 | **顶部：网易云扫码登录** · 同步参数 · 定时任务 · **音源配置** |

整理页的刮削策略与用法见 [docs/整理.md](docs/整理.md)，云盘纠错见 [docs/云盘.md](docs/云盘.md)。

> 带歌曲列表的页面（**歌单详情 / 下载 / 整理 / 云盘**）都有搜索框，支持「歌手 歌名」多词一起写，回车即筛。

侧边菜单固定贴在浏览器最左侧、通栏高度，当前页内容铺满右侧剩余区域（手机上菜单转为贴顶横条）。

各列表都能切换每页条数并翻页。所有耗时操作都有实时进度条与结果提示。

## 下载与音源

- **音源优先级**：默认「自动」＝先用网易云官方源，官方只有试听片段或已下架时自动改用第三方音源
- **手动指定音源**：每首歌右侧下拉可选「网易云官方」或任一已启用的第三方音源
  （官方源拿不到完整版、或第三方音源音质更高时用）
- **队列控制**：单首暂停/继续/取消，也能一键全部暂停/继续/取消/清空已结束
- **质量校验**：第三方音源取回的文件会校验音频文件头，并比对时长拦截试听片段

## 配置说明

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 待整理目录 | `/music/download` | 歌单下载 / 云盘下载 / 第三方搜集来的 / 本地原有的歌，容器内路径对应宿主机 `MUSIC_DOWNLOAD_DIR` |
| 整理后曲库目录 | `/music/musics` | 补齐标签/封面/歌词/专辑后的成品，对应 `MUSIC_LIBRARY_DIR` |
| 回收站目录 | `/music/_trash` | 整理页删掉的歌（可找回），对应 `MUSIC_TRASH_DIR` |
| 音乐库整理方式 | 按专辑 | 另有按歌手 / 按歌单 / 全部平铺 |
| 文件名模板 | `{track:02d}. {title}` | 变量：`{track}` `{pos}` `{title}` `{artist}` `{album}`；无音轨号时自动省略序号 |
| 音质优先级 | `jymaster,hires,lossless,exhigh,standard` | 从高到低；拿不到自动降档 |
| 同时下载数 | 3 | 1–8 |
| 每次请求间隔 | 0.35 秒 | 防风控，勿设过小 |
| 连续失败暂停 | 3 次 / 24 小时 | 避免反复重试已下架曲目 |
| 发现更高音质时重下 | 开 | 已下载曲目也会升级 |
| 下载完成后自动上传云盘 | 关 | 开启后下载成功即刻排队上传 |

## 云盘

支持单个上传与批量上传（含定时自动上传）。上传后会向网易云请求曲库匹配，
把**封面、专辑、歌手、歌词**补回本地文件与标签，并刷新数据库记录。

云盘接口依赖登录态；上传走网易云 NOS，大文件耗时较长，队列会实时显示进度。
详见 `docs/云盘.md`。

## 第三方音源

网易云对未登录、无版权或会员曲目可能只给 30 秒试听片段。此时会按启用顺序尝试
「音源配置」里的第三方音源（**洛雪 LX 兼容 JS 脚本**）取完整直链。

导入方式：填脚本链接（`https://…/latest.js`，可一键更新）或直接粘贴脚本内容。
脚本在受限沙箱里执行：禁止读写文件、禁止执行系统命令、禁止访问内部网络模块，
带加载超时、取链超时与连续失败熔断。详见 `docs/音源配置.md`。

## 音乐库目录示例

三个目录各管一段：**待整理**（下载进来、还没补齐信息的）→ 整理后进 **曲库** →
删掉的进 **回收站**（可找回）。

```
音乐/
├── download/                    # 待整理：./MUSIC_DOWNLOAD_DIR
│   └── 新下载的歌.flac
├── musics/                      # 整理后曲库：./MUSIC_LIBRARY_DIR
│   └── 安琥/
│       └── 天使的翅膀/
│           ├── 03. 天使的翅膀.flac   # 含封面与歌词标签
│           ├── 03. 天使的翅膀.lrc
│           ├── 03. 天使的翅膀.nfo
│           ├── album.nfo
│           └── cover.jpg
└── _trash/                      # 回收站：./MUSIC_TRASH_DIR
    └── 20260924-153000/安琥/天使的翅膀/03. 天使的翅膀.flac
```

三个目录要**互不包含**（别把 download 放在 musics 里面），否则同一批文件会被扫两遍。

## 常用命令

```bash
./rebuild.sh              # 改代码后增量重建（复用缓存，几秒完成）
./logs.sh                 # 查看日志（三个进程混在一起）
docker compose exec music-sync supervisorctl status      # 看三个进程状态

```

## 更新

`ncm-api` 由 Dockerfile 固定版本号安装（当前 `4.40.1`）。上游接口变动导致失效时，
改 Dockerfile 里的版本号后重新构建即可。

## ⚠️ 使用须知（重要）

- **面板本身没有任何登录/鉴权**，设计上是**只在你自己的局域网内使用**。
  不要把它映射到公网（如需外网访问，请在前面套一层带认证的反向代理）。
- 面板与网易云之间是 **HTTP**；你的网易云登录 Cookie 明文存在数据卷 `/data/config.json` 里
  （只有登录态，没有账号密码）。介意的话给宿主机磁盘加密。
- 单人使用设计：没有多用户、没有权限分级、没有 CSRF token。
- 本工具只做**你自己已购/已授权内容**的下载、整理与备份，不提供任何音乐内容本身；
  请遵守当地版权法规与网易云音乐服务条款。

## 自测

```bash
./tests/run.sh all        # 全部（云盘索引 / 上传登记 / 校准 / 监控判定 / 歌单索引 / 核心链路）
./tests/run.sh ci         # 只跑云盘索引（19 项）
./tests/run.sh mon        # 只跑歌单监控判定（14 项）
```

容器外的接口级自测（需要面板在跑；`B` 可换成你的地址）：

```bash
bash tests/organize_test.sh                 # 整理页全流程 + 回收站（删除→列表→恢复→彻底清空）
B=http://127.0.0.1:13570 bash tests/queue_api_test.sh    # 队列 / 音源 / 单曲下载
```

几个脚本需要 `docker exec` 进容器做准备，如果当前用户没有 docker 权限，
用 `ROOTRUN=/path/to/forwarder.sh` 指定一个能执行 docker 的转发脚本即可。
