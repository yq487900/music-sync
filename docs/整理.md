# 曲库整理

对音乐库里的歌曲做体检、刮削（补标签/封面/歌词）和逐首手动编辑。
刮削的匹配策略参考 [ToneCore](https://github.com/deltrivx/ToneCore) 的实测经验。

## 刮削来源（多平台）

**网易云搜不到的歌（下架/无版权）可以用别的平台的信息补齐** —— 手动匹配时选「来源」即可：

| 来源 | 代号 | 封面 | 歌词 | 说明 |
|---|---|---|---|---|
| 网易云 | wy | ✅ | ✅ | 走自建 ncm-api，信息最全；搜索结果的封面会二次补齐 |
| QQ音乐 | tx | ✅ | 去网易云找 | `c.y.qq.com` 搜索接口 |
| 酷狗 | kg | ✅ | 去网易云找 | `songsearch.kugou.com` |
| 咪咕 | mg | ✅ | 去网易云找 | `app.c.nf.migu.cn` |
| 酷我 | kw | ⚠️ 多数为空 | 去网易云找 | 公开接口不含封面字段 |

> * 非网易云的来源没有歌词接口：会拿「歌名 + 歌手」去网易云找一首**真有歌词**的补上
>   （网易云把歌下架了，歌词往往还留着）。
> * 汽水音乐没有公开搜索接口，因此不在搜索来源里（取链仍可用洛雪音源）。
> * 候选列表会显示**封面缩略图 + 歌名 + 来源 + 歌手·专辑·时长**，方便确认是不是想要的那张专辑。

## 界面结构

| 区块 | 作用 |
|---|---|
| **曲库体检** | 统计曲目总数与「缺标签 / 缺封面 / 缺歌词」的数量 |
| **刮削队列** | 批量刮削的进度，可暂停 / 继续 / 取消（有任务时才出现）|
| **曲库曲目** | 逐首列表：封面缩略图、标签信息、文件名、四个状态灯，右侧「编辑 / 刮削 / 删除」|

状态灯含义：**标签 / 封面 / 歌词 / 外来**（「外来」= 不是本工具下载的、你手动放进音乐库的文件）。

## 两种刮削方式

**自动刮削**（点「一键刮削缺的」或单首的「刮削」）
按文件现有标签（没有就用文件名）去网易云搜，打分挑最像的一首：

1. 标题相似度（先剥掉 `(深情版)` 这类括号后缀再比）
2. 歌手匹配度
3. 命中「伴奏 / 翻唱 / remix / live / 现场……」等版本噪声词就降权
4. **设了分数下限**——宁可报「没找到」，也不给你配到翻唱

歌词还有一层保险：按分数逐个候选试，**取第一个真有歌词的**
（最高分那首常是翻唱版，而翻唱多数不带歌词）。

**手动刮削**（点「编辑」→ 面板里匹配）
- **搜关键词**：给候选列表（歌名 / 歌手 / 专辑 / 时长 / id），点一条即填入表单
- **按网易云歌曲 ID**：直接填 id 点「匹配」。例如
  `5257138` → 屋顶 / 周杰伦·温岚·吴宗宪 / 男女情歌对唱冠军全记录

两者都只是**填进表单**，确认无误再点「保存」才真正写文件。

## 会写什么进文件

| 内容 | 说明 |
|---|---|
| 标签 | 歌名 / 歌手 / 专辑 / 专辑艺人 / 音轨号 / 碟号 / 年份 / 网易云 id |
| 封面 | 内嵌进文件（校验图片魔数，超过 5MB 不写，防止标签膨胀）|
| 歌词 | 写进标签 **+** 另存同名 `.lrc`（有些播放器只认外挂歌词）|

改歌名后**不会**重命名文件，也不会移动目录——避免影响 Emby 已入库的记录。

## 删除 = 回收站

删除只把文件（连同同名 `.lrc` / `.nfo`）移到 `/data/_trash/时间戳/原相对路径`，
弹窗会明确提示可找回。**不做彻底删除。**

## 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/organize/list` | 列表 + 体检（默认 20 首/页，支持 `q` 搜索）|
| POST | `/api/organize/scan` | 重新扫描（按 大小+修改时间 增量，没变的不重读）|
| POST | `/api/organize/backfill` | 把缺失的文件排进刮削队列 |
| GET | `/api/organize/item` | 编辑界面数据（标签 + 当前封面 + 当前歌词）|
| POST | `/api/organize/search` | 搜网易云候选 |
| POST | `/api/organize/match` | **按网易云歌曲 id 取详情**（含封面与歌词）|
| POST | `/api/organize/save` | 保存手改的标签 / 封面 / 歌词 |
| POST | `/api/organize/scrape` | 刮削单个文件（`preview:true` 则只填表不写）|
| POST | `/api/organize/delete` | 移入回收站 |
| GET | `/api/organize/queue` | 刮削队列状态 |

## 安全边界

* 所有涉及路径的接口都限制在音乐库目录内，**库外路径一律拒绝**（实测 `/etc/passwd` 被拦）。
* 上传的封面必须通过图片魔数校验，否则拒绝。
* 单个文件刮削失败不影响其它文件。
