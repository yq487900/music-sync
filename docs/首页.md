# 首页（音乐同步控制台）

## 顶部：账号信息

自动读取当前登录的网易云账号（缓存 10 分钟）：

- 头像 + 昵称 + UID
- 网易云等级（Lv.x）+ 累计听歌数
- 歌单数（自己创建的 / 收藏的）
- 会员状态：**黑胶VIP Lv.x + 到期日期**（没开通会标黄）
- 云盘占用：已用 / 上限 + 云盘歌曲数

## 概览小卡片

| 卡片 | 内容 |
|---|---|
| 已勾选歌单 | 配置里勾选的歌单数 + 已同步入库的歌单数 |
| 曲目总数 | 曲目总数 + 其中已勾选 |
| 已下载到本地 | 本地已下载数 + 已上传云盘 / 待上传 |
| 待下载 / 失败 | 待下载数 / 失败数 |
| 云盘歌曲 | 云盘总数 + 其中在歌单里的数量 |
| 云盘缺封面 / 无信息 | 网易云没认出来的条数（这些匹配不了） |
| 云盘容量 | 占用百分比 + 已用 / 上限 |
| 本地曲库文件 | 「整理」页扫描到的文件数 |
| 回收站 | 回收站里的曲目数 + 占用空间 |
| 歌单监控 | 开 / 关 + 方式 + 上次检查结果 |
| 云盘索引 / 歌单索引 | 索引条数 + 多久之前刷新的（正在刷新会标出来） |
| 队列状态 | 空闲 / 进行中 + 下载 / 上传的完成与失败数 |

数据来自 `GET /api/home`（一次请求拿全部，不逐个接口拉）。

## 手动操作

「立即同步歌单」「下载勾选的曲目」「刷新本页」——刷新只重拉首页数据，不动数据库。
