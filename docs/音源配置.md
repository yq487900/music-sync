# 音源配置

> 参考项目：[qwex888/miyin](https://github.com/qwex888/miyin)（觅音）的音源管理方式

## 为什么需要

网易云对以下情况可能只返回 **30 秒试听片段**（接口里的 `freeTrialInfo`）或干脆没有地址：

- 未登录 / 登录态过期
- 曲目无版权、已下架
- 会员专享曲目

此时 MusicSync 会按**启用顺序**依次尝试「音源配置」里的第三方音源取完整直链。
取链顺序是**先网易云、后第三方**：网易云能拿到完整直链就不动用第三方。

## 音源是什么

**洛雪（LX Music）兼容的 JS 脚本**。脚本通过 `globalThis.lx` 与宿主交互：

```js
/* @name 示例音源 @version 1.0.0 @author 某人 */
const { EVENT_NAMES, on, send } = globalThis.lx

// 宿主请求取链时回调
on(EVENT_NAMES.request, ({ action, source, info }) => {
  if (action !== 'musicUrl') return null
  // source: 'wy'（网易云）/ 'kw' / 'kg' / 'tx' / 'mg'
  // info.type: 音质档位，如 '320k' / 'flac'
  // info.musicInfo: { id, name, singer, albumName, interval, ... }
  return 'https://…/xxx.flac'      // 返回直链，或 { url: '…' }
})

// 声明自己支持的平台与音质档位
send(EVENT_NAMES.inited, {
  status: true,
  sources: { wy: { name: '网易云', qualitys: ['320k', '128k'] } }
})
```

脚本可用的环境：

| 提供 | 内容 |
|---|---|
| `lx.request(url, {method, headers, body}, cb?)` | 发 HTTP 请求（支持 Promise 与回调两种写法） |
| `lx.utils.crypto` | `aesEncrypt` / `rsaEncrypt` / `randomBytes` / `md5` |
| `lx.utils.buffer` | `from` / `bufToString` |
| `lx.utils.zlib` | `inflate` / `deflate` |
| `console` | 日志会被收集，检测时可见 |
| 全局 | `Buffer` / `URL` / `TextEncoder` / `TextDecoder` / `setTimeout` / `setInterval` |

## 导入方式

在「配置 → 音源配置 → 添加音源」：

1. **脚本链接**：填 `https://…/latest.js`，会自动下载脚本；之后可点「更新」重新拉取
2. **直接粘贴**：把脚本内容贴进文本框

保存时会自动做一次**检测**，通过才显示为「可用」。列表里可以：

- **启用 / 停用**：只影响是否参与取链
- **检测**：重新加载脚本，看平台与音质档位
- **更新**：按记录链接重新下载脚本并检测
- **删除**

## 沙箱限制（安全边界）

第三方脚本按「不可信代码」处理：

- **禁止** `require('fs')`、`child_process`、`os`、`net`、`worker_threads`、`vm` 等模块
- 只能通过 `lx.request` 访问网络（仅 http/https，单次 15 秒超时，响应体上限 8 MB）
- 脚本初始化 8 秒超时（死循环会被中断）
- 未发送 `inited` 的脚本判定为初始化失败（12 秒上限）
- 取链单次 25 秒超时
- 定时器数量上限 32
- 连续失败 3 次后**熔断 60 秒**，避免拖慢整轮下载
- 脚本体积上限 2 MB

## 取链结果的校验

第三方音源拿回的直链**不能直接信任**，因此下载后会：

1. **按文件头判断真实格式**（`ID3`/`fLaC`/`OggS`/`ftyp`/`RIFF`），不是音频就丢弃
2. **比对时长**（用曲目元数据里的时长，容差 15 秒），明显偏短判定为试听片段并丢弃
3. 通过后才打标签、写歌词与 NFO、移入音乐库

失败原因会记在「下载」页对应曲目下方，例如：
`第三方音源（某音源）只返回了试听片段（30s / 应为 220s）`

## 在歌曲上单独指定音源

歌单详情页与下载页的每首歌右侧都有音源下拉框，可选：

| 选项 | 行为 |
|---|---|
| **自动（网易云优先）** | 默认。先用网易云官方源；官方只有试听片段或已下架时，按启用顺序改用第三方音源 |
| **网易云官方** | 只用官方源，失败就报错（不想用第三方时选它） |
| 某个第三方音源 | 只用指定的这一个音源；它取不到时提示改回「自动」 |

选择会记在数据库里（`tracks.source_pref`），下次批量下载也沿用；下载成功后
实际使用的音源名会显示在曲目右侧（`@音源名`）。

## 相关接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sources` | 列出音源与沙箱状态 |
| POST | `/api/sources` | 添加（`{name, url?, script?}`） |
| PATCH | `/api/sources/{id}` | 启用/停用（`{enabled}`） |
| DELETE | `/api/sources/{id}` | 删除 |
| POST | `/api/sources/{id}/check` | 重新检测 |
| POST | `/api/sources/{id}/update` | 按链接重新拉取脚本 |
